# 📊 Student Performance Analyzer

A Python-based Student Performance Analyzer built using NumPy to analyze students' academic performance and generate useful statistical insights.

##   Project Overview

This project uses NumPy to analyze students' subject-wise marks and calculate different performance statistics.

It demonstrates the practical use of NumPy concepts such as arrays, axis-based calculations, Boolean indexing, sorting, and statistical functions.

##   Features

- Store student marks using NumPy arrays
- Calculate student-wise averages
- Calculate subject-wise averages
- Find highest and lowest marks
- Find the best and lowest-performing students
- Calculate class average
- Calculate median marks
- Calculate standard deviation
- Perform Pass/Fail analysis
- Find subject-wise toppers
- Rank students based on average marks
- Filter students with average marks above 80
- Generate a final performance report

## 📊 Analysis Performed

### Student-wise Analysis

- Calculates the average marks of each student.
- Identifies the best and lowest-performing students.
- Ranks students based on their average marks.

### Subject-wise Analysis

- Calculates the average marks of each subject.
- Identifies the highest-performing student in each subject.

### Class Statistics

- Calculates the overall class average.
- Calculates the median marks.
- Calculates the standard deviation.
- Finds the highest and lowest marks.

### Pass/Fail Analysis

Students are considered **Pass** if they score at least 50 marks in every subject.

### High Performer Analysis

Identifies students whose average marks are above 80.
